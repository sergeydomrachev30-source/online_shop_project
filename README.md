# Проект интернет-магазина

## Функционал
- **Класс `Product`**: Хранение данных о товаре (название, описание, цена, количество).
- **Класс `Category`**: Группировка товаров, хранение описания и списка продуктов.
- **Загрузка из JSON**: Функция `load_data_from_json` для инициализации объектов классов из внешних файлов.

## Иерархия товаров и валидация
- **Наследование**: Реализованы специализированные классы `Smartphone` и `LawnGrass`, наследующиеся от базового класса `Product`.
- **Строгая типизация сложения**: Метод `__add__` теперь позволяет складывать только товары одного и того же класса (например, смартфон со смартфоном), предотвращая логические ошибки при расчете стоимости.
- **Контроль целостности категорий**: Метод `add_product` в классе `Category` проверяет, является ли добавляемый объект экземпляром `Product` или его наследником, исключая попадание некорректных данных в список товаров.
