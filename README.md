# Проект интернет-магазина

## Функционал
- **Класс `Product`**: Хранение данных о товаре (название, описание, цена, количество).
- **Класс `Category`**: Группировка товаров, хранение описания и списка продуктов.
- **Загрузка из JSON**: Функция `load_data_from_json` для инициализации объектов классов из внешних файлов.

## Технологии
- **Python 3.11+**
- **Poetry** (управление зависимостями)
- **Pytest** (тестирование)
- **Pytest-cov** (отчеты о покрытии)
- **Flake8 / Mypy** (проверка стиля и типизации)
